# Car Search 项目交接文档

> 更新日期：2026-10-18

---

## 一、项目概述

车辆信息查询平台，支持多种车辆数据查询服务（维保、事故、里程、新能源电池等）。技术栈：

- **后端**：Spring Boot 4.1.1 + Jackson 3.x + MySQL + HikariCP
- **前端（小程序）**：UniApp / Vue 3
- **管理后台**：原生 HTML/JS 单页应用

---

## 二、已完成的功能

### 1. Spring Boot 后端迁移

- 从旧 PHP 后端完整迁移到 Spring Boot
- 包含用户认证、订单管理、支付、查询执行等全部核心模块

### 2. 供应商查询引擎（ProviderService）

支持三种查询模式：

| 模式 | 说明 | 示例 |
|------|------|------|
| `single` | 同步单次请求 | 汽修宝 VIN 查询 |
| `async` | 异步两步查询（下单 → 轮询获取报告） | 新能源电池报告 |
| `callback` | 回调模式（下单 → 供应商推送结果 → 降级轮询） | 带回调的供应商接口 |

### 3. 回调模式（Callback）

- 供应商通过 `POST /api/v1/callback/query` 推送查询结果
- 请求头 `HTTP-X-CA-PROXY-SIGNATURE` 进行 MD5 签名验证
- `callback` 参数不参与签名计算，但需要传给供应商
- 回调超时后自动降级为轮询模式获取结果

### 4. 图片上传功能

- `POST /api/v1/upload/image` 支持行驶证等图片上传
- 文件校验：JPEG/PNG/WebP，最大 5MB，尺寸 100×100 ~ 4096×4096
- 存储路径：`{storage-path}/uploads/{type}/{yyyyMMdd}/{random}.{ext}`
- 小程序端通过 `uni.uploadFile` 上传，返回可访问的 URL

### 5. 可配置的 ID 字段路径（id_field_path）

不同供应商下单接口返回的 ID 字段名不同（`query_id`、`order_id`、`task_id` 等），通过 `id_field_path` 配置项支持自定义路径提取：

- 支持点号路径，如 `result.query_id`、`data.task_id`
- 留空则自动尝试常见字段名（向后兼容）

### 6. 独立的报告接口版本号（fetch_api_version）

异步两步查询中，下单接口和获取报告接口可能使用不同版本号：

- `api_version`：下单请求的版本号
- `fetch_api_version`：获取报告请求的版本号
- 留空则回退使用 `api_version`

### 7. 结果展示 Schema

`result_schema` 配置项控制查询结果的展示格式：

- 扁平字段：`{"vin": "VIN车架号"}` → 点号路径提取
- 数组字段：`{"content[]": "维保记录"}` → `[]` 后缀标记数组，返回全部元素
- 嵌套对象自动保留结构递归格式化
- 时间戳自动转换为可读日期（`ResultValueFormatter`）

### 8. 管理后台增强

- 服务编辑器支持所有新增配置项
- 模拟回调测试功能
- 新能源电池报告结果分组展示（电池充电/健康/信息/车辆/里程核验）

## 三、数据库升级脚本

升级需按顺序执行以下 SQL 脚本（位于 `database/` 目录）：

```sql
-- 1. 回调功能支持
database/upgrade_callback.sql

-- 2. 供应商管理
database/upgrade_provider.sql

-- 3. 可配置 ID 字段路径
database/upgrade_id_field_path.sql

-- 4. 独立报告接口版本号
database/upgrade_fetch_api_version.sql

-- 5. 修复旧数据
database/fix_old_services.sql
```

## 四、配置说明

### application.yml 关键配置

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 5MB        # 单文件最大
      max-request-size: 6MB     # 单次请求最大
  server:
    tomcat:
      max-http-form-post-size: 10MB

car:
  storage-path: ./runtime/uploads       # 文件上传存储路径
  callback-base-url: https://xxx.com    # 供应商回调基础 URL
  data-encrypt-key: ${DATA_ENCRYPT_KEY} # 数据加密密钥
  wechat:
    app-id: ${WECHAT_APP_ID}
    app-secret: ${WECHAT_APP_SECRET}
```

### 环境变量

| 变量 | 说明 |
|------|------|
| `DB_URL` | 数据库连接地址 |
| `DB_USERNAME` | 数据库用户名 |
| `DB_PASSWORD` | 数据库密码 |
| `DATA_ENCRYPT_KEY` | 数据加密密钥（64位hex） |
| `WECHAT_APP_ID` | 微信小程序 AppID |
| `WECHAT_APP_SECRET` | 微信小程序 AppSecret |
| `CAR_CALLBACK_BASE_URL` | 供应商回调基础URL |
| `CAR_STORAGE_PATH` | 文件上传存储路径 |

## 七、部署说明

### 打包

```bash
cd backend
mvn -DskipTests package
# 产物：backend/target/car-search-backend-0.1.0-SNAPSHOT.jar
```

### 运行

```bash
java -jar car-search-backend-0.1.0-SNAPSHOT.jar --spring.profiles.active=local
```

或使用脚本：

```powershell
.\start-backend.ps1
```

```bash
cd miniapp

npm run dev:mp-weixin   # 开发环境
npm run build:mp-weixin  # 生产环境
```

## 九、注意事项

- `application-local.yml` 包含数据库密码，已加入 `.gitignore`，不提交到仓库
- 供应商签名算法为 MD5：`sign = md5(sorted_params + api_key).toUpperCase()`
- `callback` 参数不参与签名，但需要传给供应商
- 微信登录的 `session_key` 只存在后端，绝不返回给前端
- 关键状态（支付、退款）必须由后端验证，不信任客户端传入
