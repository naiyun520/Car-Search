# 车辆信息查询系统

本项目包含两个独立应用：

- `car-miniapp`：UniApp Vue 3 微信小程序，提供动态查询服务、微信官方虚拟支付、结果报告、历史订单和投诉意见。
- `car-admin`：ThinkPHP 8 API 与企业风格管理后台，提供用户、订单、支付开关、查询接口、公告、客服、反馈和审计管理。

## 核心业务闭环

1. 小程序使用 `wx.login` 换取服务端令牌。
2. 用户选择服务、填写信息并确认合法授权。
3. 服务端校验并加密查询入参，创建待支付订单。
4. 小程序调用微信官方虚拟支付；服务端通过微信官方订单查询接口核验状态和金额，不信任客户端成功回调。
5. 已支付订单原子进入查询中状态，服务端调用供应商接口。
6. 供应商业务码为 200 时仅返回整理后的 `data`；`user_info` 永不透传。
7. 其他供应商状态统一向用户显示“当前查询超时，可联系客服处理”，后台可核实并恢复重试。

## 开始部署

后端提供首次安装页面：配置 Composer 与网站运行目录后，直接访问域名即可自动进入安装页面。安装时只填写数据库信息，程序自动建表并创建默认后台账号 `admin / 123456`。微信、支付和供应商配置在后台填写。

完整宝塔步骤、旧版本升级及密码恢复见 `car-admin/README.md`；小程序构建见 `car-miniapp/README.md`。正式上线前必须替换 API 域名、AppID、支付凭证、供应商密钥和客服电话。

原始接口文档中的明文供应商密钥已脱敏。由于旧密钥曾进入文档和开发上下文，上线前仍须在供应商平台全部轮换。
