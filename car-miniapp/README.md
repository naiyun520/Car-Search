# 车辆信息查询小程序

基于 UniApp Vue 3，目标平台为微信小程序。

## 运行

1. 修改 `src/config.js` 的 HTTPS API 域名，并在微信公众平台配置 request 合法域名。
2. 修改 `src/manifest.json` 的微信小程序 AppID。
3. 首次执行 `npm ci`，之后运行 `npm run build:mp-weixin`。不要中断依赖安装，否则可能造成 DCloud 编译器内部文件缺失。
4. 在微信开发者工具中导入 `dist/build/mp-weixin`。当前发布版本为 `1.1.4`，结算协议版本为 `20260814.5`。
5. 使用具备虚拟支付资格的企业小程序账号真机验收；开发者工具不能完成真实虚拟支付。

## 页面闭环

- 首页：公告、模糊搜索、11 项动态服务。
- 查询：动态字段、格式校验、授权确认、官方虚拟支付。
- 结果：结构化报告、订单信息、隐私提示。
- 我的：个人信息、历史订单、在线客服、客服电话、投诉意见、协议声明。
- 历史订单：已支付续查、成功查看、异常客服处理；未付款订单由查询页按原订单恢复，避免重复创建。

虚拟支付无法在普通浏览器或无资格 AppID 下完整测试，必须使用微信开发者工具和真机沙箱验收。iOS 可用范围、类目和虚拟商品规则以当前微信平台审核要求为准。
